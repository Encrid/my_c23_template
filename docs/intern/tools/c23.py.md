# tools/c23.py

`c23.py` finds the older spellings of C in the code of the project.
C23 gives a newer spelling for each of them, and the project uses the newer spelling.
`c23.py` reads the same files as `tools/style.py`. It does not read the comments and the strings.

```sh
python tools/c23.py [--root <folder>]
```

## The spellings

| Older spelling | Newer spelling |
| --- | --- |
| `NULL` | `nullptr` |
| `#include <stdbool.h>` | Nothing. `bool`, `true` and `false` are keywords. |
| `_Bool` | `bool` |
| `_Alignof` | `alignof` |
| `_Alignas` | `alignas` |
| `_Static_assert` | `static_assert` |
| `_Thread_local` or `THREAD_LOCAL` | `thread_local` |
| `_Noreturn` | `[[noreturn]]` |
| `__attribute__` or `__declspec` | An attribute in brackets, for example `[[gnu::cold]]` |
| `enum {`, an `enum` with no name | A named `enum` with its width, for example `enum kind : uint32_t {` |
| `enum kind {`, an `enum` with no width | The `enum` with its width |
| `(void)name;` | `[[maybe_unused]]` on the declaration of the parameter |
| `= {0};` | `= {};` |
| `#define NAME 4`, a macro for a number | A typed `constexpr`, for example `constexpr int NAME = 4;` |

## The rules and C23

C23 gives a better spelling to some rules of `docs/intern/tools/style.py.md`:

- G4 and H3: a constant with a name is a typed `constexpr`. It is a constant global variable for G4, and it is not a macro.
- V1: an `enum` has a name and a width, for example `enum kind : uint32_t`.
- H1: the attributes of a function are in the brackets of C23, for example `[[nodiscard]]` and `[[maybe_unused]]`.

One spelling of C23 does not replace a rule: C23 lets `f()` declare a function with no argument, but F5 requires `f(void)`.

## Output

`c23.py` gives each older spelling to `report` of `tools/shared.py`, as a fault: `<path>:<line>: <older>  ->  <newer>`.
`report` writes each fault on its own line, then stops: `faults: <number>`. If there is no fault, it writes `no fault in <number> files`.

## Functions

| Function | Result |
| --- | --- |
| `main()` | Reads the files, and writes each older spelling. |
