# src/sample.c

`sample.c` is the source of the program `sample` of the template.
The program writes the line `hello, c23`, and ends with the exit status 0.
It uses some features that C23 adds: `static_assert` with no message, `alignof`, `bool`, `true` and `nullptr`.
A project replaces `sample.c` with its own sources.
`tests/cases/sample.toml` checks the program.
